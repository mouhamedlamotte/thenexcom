# Personnage

L'illustration du développeur en version bêta : grain pointillé, fond noir, annotations de construction en pointillé sur les vêtements.

Sur un fond `nuit`, l'utiliser en mode de fusion « écran » (CSS `mix-blend-mode: screen`) : le noir disparaît et le personnage prend la teinte bleutée de la DA. Ne pas lui ajouter d'accessoire ni de logo.
