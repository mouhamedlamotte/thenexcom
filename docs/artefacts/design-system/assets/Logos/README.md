# Logos

Le logo nexcom et son icône, en SVG vectorisés (le texte est converti en tracés, aucune police à installer).

- `nexcom-logo-fond-sombre.svg` : texte craie, fond transparent, pour poser sur `nuit` ou `indigo`.
- `nexcom-logo-fond-clair.svg` : texte nuit, fond transparent, pour poser sur `craie` ou du blanc.
- `nexcom-logo-sur-nuit.svg` : le logo avec son fond nuit.
- `nexcom-icone.svg` : les chevrons sur un carré nuit aux coins arrondis (photo de profil, app).
- `nexcom-icone-carre.svg` : la même sur un carré plein, pour les plateformes qui arrondissent elles-mêmes.
- `nexcom-chevrons-seuls.svg` : les chevrons corail seuls, fond transparent, pour les signatures « >< ».

Les chevrons sont toujours en corail #F2604A.
